# Classical transparent frame artwork

Generated with the built-in ImageGen tool with `transparent_background: true`.

Assets:
- `laurel-corner.png`
- `scrollwork-corner.png`
- `regal-corner.png`

Each asset is a square corner fragment displayed with its original aspect ratio and mirrored at the other corners. Scrollwork and regal preserve the raster engraving; laurel uses its transparent alpha to match the theme ink.

## Final prompt set

Each request used the following common prompt, with the corresponding description inserted after the asset type:

> Use case: stylized-concept. Asset type: transparent invitation frame CORNER artwork for web implementation. [Description] Produce a square isolated TOP LEFT corner ornament only, not a full rectangular frame. Ornament extends in an L shape along the top edge and left edge with the interior and lower-right mostly empty and truly TRANSPARENT. All strokes and decorative marks clean solid dark charcoal ink with alpha, no paper, no backdrop, no photographs, no shadows, no texture behind the artwork, no text, no watermark. Artwork occupies approximately 85% of square; keep ~6% transparent safe padding around bounds. Design for repeating by mirroring at the other 3 corners of an invitation. Consistent visible 8-12px equivalent engraving lines at 1024px canvas so lines remain legible scaled down to 100px. Professional fine engraved stationery ornament, graceful deliberate composition, vector-like clarity but natural detailed engraving. No emoji, no clipart. Transparent background is mandatory.

Descriptions:

- Laurel: An exquisite restrained laurel corner, slender winding stem along the top and left edges, carefully engraved paired olive leaves, balanced classical invitation stationery. Richly detailed but not fussy. No flowers.
- Scrollwork: Refined antique copperplate scrollwork, graceful acanthus curls, subtle intertwined thin strokes, an elegant rococo corner for high-end formal invitation stationery. Structured, symmetric along a diagonal, sophisticated not cartoonish.
- Regal: A formal neoclassical engraved corner ornament, stepped fine double rules meeting a small elegant acanthus crest, subtle leaf filigree and tiny bead accents. Architectural restrained regal stationery, polished and balanced.
