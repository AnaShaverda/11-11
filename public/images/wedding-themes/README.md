# Wedding stationery artwork

30 separate transparent raster assets for the ten approved wedding design boards.
Generated with the built-in image_gen tool using each approved board as reference.
Frames, botanical/crest ornaments and event illustrations are independent files.
Original generated pixels and alpha are preserved in lossless WebP files.
Exact prompts, reference paths and generated source paths are in prompts.json.

Responsive rendering keeps illustrations and ornaments at their original aspect ratio.
Covers show the complete frame. Supporting sections use a continuous quiet border and naturally proportioned ornament layers anchored independently to their top and bottom edges. Long content expands the section; its bottom decoration follows that height.
No SVG frame artwork. Theme settings are fixed; optional footer selection is independent.

Two seasonal themes extend the collection: Autumn Promise and რთველი. New independent transparent leaf and grapevine ornament compositions pair with existing classical frames. Autumn uses the warm venue illustration; რთველი uses the existing vineyard illustration.

Pearl Letter v2 replaces the central crest with sparse ivory camellias, pearl beads and silk ribbons at opposite corners. Generated with built-in image_gen, transparent pixels preserved.
