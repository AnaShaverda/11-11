# Card font assets

User-supplied files from `drive-download-20261002T162527Z-1-001`.
These families are used only for selected display text inside invitation artwork;
website copy, navigation, labels, controls, dates and locations retain the main font.

- Casmera: formal and floral headings.
- Magnola: soft stationery and christening headings.
- Zalino: editorial wedding and dinner-card headings.
- Elegance Natural Valentine: romantic bridal and ribbon-card headings.
- Birthday: short handwritten names and accents.

None of these files includes Georgian letters. Each display stack pairs them with
the existing local Noto Serif Georgian. Casmera and Magnola demo files contain only
letters, so their CSS coverage is restricted to English A–Z/a–z and punctuation
falls back to the complete serif family. Fonts load on demand with `font-display: swap`.

The supplied Casmera, Magnola and Zalino readmes describe personal-use demo fonts.
Their original notices are preserved beside the assets. Commercial deployment
requires the appropriate licenses/full font files. Supplying files does not establish
commercial licensing for Birthday or Elegance Natural Valentine either.
