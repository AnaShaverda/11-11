# Two spider birthday directions

Approved directions: City After Dark and Comic Cutout. Both are now separate full-screen invitation experiences. Retro Sport and Upside Down are retired from discovery; their previous URLs redirect to the corresponding new theme.

The implementation serves adults and children equally: the demo celebrates a 26th birthday, age can be changed or omitted, language avoids child-only framing, and artwork uses the existing graphic spiders rather than the moodboards' cartoon mascots. The preview customization controls also update the date, time, venue, calendar file and schedule.

## City After Dark

Midnight rooftop adventure. Navy #081A2D, cobalt #125DEB, scarlet #F3322B, cream #F5EBDD. Oversized condensed type, panoramic illustrated buildings, moonlight, fine webs and restrained print grain.

Optional game: Rooftop Swing. Release the web when the marker enters the cream zone. Complete six landings in a forgiving round with no time limit. A single large touch control, keyboard activation, restart, pause and a clear skip link keep it accessible. Reduced motion offers an untimed press-to-advance alternative. Finishing reveals a celebratory birthday message; event information and RSVP are always available.

## Comic Cutout

An invitation imagined as a collectible birthday comic issue. Cream #F6EEDD, scarlet #EF342B, cobalt #075EB9, ink #101E32. Cut paper skylines, halftone corners, enormous playful headlines and sparse handwritten annotations.

Optional game: Party Rescue. Tap six illustrated SVG marks to web them together above the city. Each collected piece adds a web strand. Keyboard users select the same objects with Tab and Enter. No time pressure; replay is optional.

Every main chapter should span the full viewport width and use a minimum height of 100svh, with content-driven expansion instead of clipping. Account for header height and safe areas. Mobile uses recomposed artwork and stacked content; landscape phones use shorter art and natural overflow. Do not force scroll snapping. Desktop pointer parallax is decorative; touch devices get equivalent tap interactions. Respect reduced motion and never require a game win to respond. Use InvitationArtwork and existing SVG assets for all UI icons, preserve Georgian localization, and keep game audio off until explicitly enabled.

Generated moodboards remain art direction references. The implemented pages use live HTML text and controls over separate optimized WebP city illustrations. Names, dates and venues are illustrative. RSVP is a device-local demo, matching the other invitation previews.
