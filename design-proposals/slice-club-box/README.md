# Slice Club — Open a box of good times

Design exploration only. No changes to the live Slice Club page.

The vision board preserves the existing cornflower, cream scalloped paper and tomato-red printed slice identity. Palette: #8CAED0, #FAF2DC, #C71F2B, #233D58, #F1CF78. Patterns: blue gingham, scallop edges and restrained red pizza print.

The first cover is a closed illustrated pizza box. Pressing Open reveals the pizza and invitation details inside the same cover. Closed/open boxes need matching perspectives and separable lid, base and pizza artwork for implementation. Generated copy on boxes, paper and keepsakes is concept-only; use blank art with live localized text, as requested for the other invitation. Preserve the real project maker logo and text-only non-fixed header. Do not add generated mobile close/save icons, emoji, glyph decorations or confetti.

The game storyboard shows Roll, Top, Bake and Ready states within one section. Roll supports dragging the pin and an equivalent tap/keyboard action. Top supports food-image buttons, selection and undo. Bake offers an illustrated oven transition. Ready displays the player's pizza and live editable pizza name, with Make another and Back to the party. Game is optional and must not gate RSVP. No real cooking instructions, timers or scores.

Five scroll chapters: cover, details, game, wishes, RSVP/footer. Cover opening and game stages are states, not extra scroll sections. Each chapter has viewport-height intent with natural overflow and mobile recomposition. Keep device-local demo disclosures, English/Georgian text, reduced-motion handling and bidirectional scroll reveals. For the wishes artwork, preserve the established mobile-hidden treatment unless the user chooses otherwise.
