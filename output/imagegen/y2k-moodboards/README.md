# Y2K invitation design exploration

Concept references only. Existing invitation UI has not been edited. Generated with the built-in image_gen tool; exact prompts are in prompts.json. Names, dates, venues and copy inside the images are illustrative placeholders. The implementation should retain Georgian localization.

## Directions

1. Chrome Club: cobalt, icy white and reflective silver; editorial club aesthetic; rhythm-tap game.
2. Desktop Sleepover: pink and lavender, messenger windows, photo strips and translucent plastic; memory-match game. This image explores materials and composition rather than a verified responsive layout.
3. Pocket Arcade: butter yellow, purple and cobalt; cartridge invitation, full-width sections and a CD-catching mini-game. Includes desktop and mobile references.

## Recommended structure

Header with Details, Play and RSVP anchors; hero containing the invitation card; clear date/time/venue/dress code; optional mini-game; soundtrack and song request; RSVP; designed footer. Section backgrounds span the viewport, with readable constrained content. Mobile stacks content, keeps controls comfortably tappable, and offers direct RSVP access. The game must be optional, support keyboard and touch, have pause/restart, and avoid autoplay audio. Respect reduced motion.

## Game concept

CD Catch: an original 30-second arcade game. Drag a tray on mobile or move it with left/right keys on desktop to catch falling CDs. Show score, restart and a clear path to RSVP. Use original artwork and the existing project SVG icon system.

Alternative: a short original rhythm-tapping challenge inspired by Nintendo DS rhythm games. Sound starts only after the guest presses Play. Provide a visual timing cue and a non-game RSVP path.

## Research

- [Paperless Post invitations](https://www.paperlesspost.com/cards/section/invitations?coins=0): stationery-inspired cards, animated flyers, shareable invitations and RSVP tracking. Design takeaway: preserve a distinctive invitation centerpiece and simple response action.
- [Partiful](https://help.partiful.com/en-us/articles/15525594-why-use-partiful): shareable event pages, RSVP, guest questions and post-event photos. Design takeaway: pair visual personality with useful guest information.
- [WarioWare: Touched!](https://www.nintendo.com/en-gb/Games/Nintendo-DS/WarioWare-Touched--273564.html): Nintendo DS touch microgames, a reference for brief simple interactions.
- [Rhythm Paradise](https://www.nintendo.com/en-gb/Games/Nintendo-DS/Rhythm-Paradise-272750.html): Nintendo DS title released in Europe in 2009, using stylus rhythm interaction. A reference for a music-focused party game.

These references inform the proposed direction; the generated images are original concepts, not screenshots of these services. Generated layouts are not evidence of tested responsive behavior.
